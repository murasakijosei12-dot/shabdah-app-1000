Mobile Lookup Bookmarklet

Look up any word on any webpage with a single tap. Works in Safari, Chrome, and any mobile browser.

Shabdah Lookup

Drag this button to your bookmarks bar, or follow the instructions below for mobile.

Installation Instructions

  1. Copy the bookmarklet code
    Tap the button below to copy the bookmarklet code to your clipboard.
    javascript:(function(){var t=window.getSelection().toString().trim();if(t)window.open('https://shabdah.app/index.html?q='+encodeURIComponent(t),'_blank');else alert('Select some text first');})();
  2. Add any bookmark
    In Safari, tap the Share button (square with arrow) and choose Add Bookmark. Save it anywhere.
  3. Edit the bookmark
    Open your Bookmarks, find the one you just added, tap Edit, then replace the URL with the code you copied.
  4. Rename it
    Change the name to something short like Shabdah Lookup or Lookup.
How to use: On any webpage, select a word or phrase by long-pressing it. Then tap the bookmarks icon and choose your Shabdah Lookup bookmark. The definition will open in Shabdah.

Other Ways to Look Up Words on Mobile

Share to Shabdah (Android)

If you've installed Shabdah as an app (Add to Home Screen), you can share selected text directly to it. Select text in any app, tap Share, and choose Shabdah.

Copy and Paste

Copy any word, then open Shabdah. If you have text on your clipboard, you'll be prompted to look it up automatically.

Reader Mode

Paste any text or article into Reader Mode to turn every word into an interactive, tap-to-inspect flashcard with audio and example sentences.
